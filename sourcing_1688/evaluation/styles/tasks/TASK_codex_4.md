# Задача: описать предметы бижутерии по фото и отнести каждый к стилям

Работай только с локальными файлами этой папки. Сеть, браузер и MCP не нужны.

1. Прочитай `СТИЛИ.md` — справочник стилей, шаблон описания и правила спорных случаев.
2. Открой и посмотри листы `sheets/NNN.jpg` из диапазона ниже. На каждом листе 12 предметов, номер — под фото (`№123`). Если деталь не видна, открой отдельное фото `img/0123.jpg` (номер четырёхзначный). У сборных пар на одном фото два предмета: слева колье, справа серьги.
3. Для КАЖДОГО предмета:
   - опиши его по шаблону из `СТИЛИ.md`, 12–30 слов, только то, что видно;
   - отнеси к стилям по определениям: коды из справочника, основной стиль — один.

Ничего не выдумывай. Если не видно — так и пиши.

**Выход** — JSON-файл, путь ниже. Ключ — номер предмета строкой:
`{"123": {"описание": "...", "стили": ["SCULPT", "PEARL"], "основной": "SCULPT", "brand": false}}`

Дописывай файл после каждого листа, чтобы результат не потерялся. Других файлов не меняй. В конце — одна строка: сколько предметов описано.


**Твой диапазон:** листы `sheets/094.jpg` … `sheets/124.jpg` (предметы №1117–1485).
**Файл результата:** `out/codex_4.json`
