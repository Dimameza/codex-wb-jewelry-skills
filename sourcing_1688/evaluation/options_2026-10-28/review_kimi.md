# Ревью плана закупки бижутерии (Kimi, 28.10.2026)

## 1. Ошибки и слабые места

**Оценка уже найденного.** Мультипаки, браслет в наборе, логистика, СПП 30–40 % — согласен, данные не противоречат. По №108/114/111/199: перевод в тест минус не лечит (unit-экономика та же), нужен пересчёт цены или отказ; при этом №199 имеет запас к рыночной медиане 65 % (headroom 1,65) — в «минусовые» её включать без отдельного обоснования нельзя. Серьги 108/111/114 по 4 раза в наборах (потребность 100 пар на наборы + 50–100 шт поштучно) — подтверждаю, цифры сходятся.

**Новое:**
1. **Минусовая зона шире четырёх позиций.** Headroom = медиана витрины группы / (need×0,65). У 45 из 322 «оплатить» запас <15 %, у 8 — <10 %: 1343, 354, 1048, 349, 1327, 1162, 1155, 108, 111, 114, 829, 927… Для них СПП 40–45 % или просадка цены конкурентами = убыток. Подтверждение цены построено на хвосте выдачи («≥5 карточек»), а не на медиане группы.
2. **Наборы sets_56 перевёрнуты целиком, а не частично:** порог всех 56 наборов 925–1443 ₽ (медиана 1217) при медиане аналогов 909 ₽. Проданные по рынку (909 витрина), набор с cost ≈ 294 ₽ дают ROI ~15–20 % вместо 100 %. 36/56 — из компонентов <55 баллов, 45/56 колье — индивидуальные «не брать». Это сбыт непрошедшего отбор товара, а не тест.
3. **Комплекты = 65 % бюджета «оплатить»** (195 SKU, ¥189,5k из ¥291,8k) — та же категория с медианой рынка 909 ₽ ниже нужной витрины у десятков позиций. Риск сконцентрирован.
4. **Дубли между файлами:** 20 кластеров / 41 позиция с идентичными сегмент+стиль+¥+need, с конфликтами решений: 838/839 (1000-ч1, тест) = 1365 (добор, оплатить) при тех же ¥11,50/need 1439; 383 (тест) vs 619 (оплатить); 151 vs 367; 906 vs 916. Оплата обоих файлов = двойной заказ SKU и двойные карточки на WB.
5. **Кол-во_план у тестов не исправлено:** в CSV у 644 тестов стоит 50–100 шт → по файлу тесты стоят ¥583,5k вместо ¥158k. Заказ по CSV раздует тесты в 3,7 раза.
6. **Варианты не сходятся:** «две волны ¥315k» = только оплатить+наборы; «¥210k» получается только без наборов (с ними — 231k). Подписи вариантов плавают, состав надо фиксировать.

## 4. Конкретные правки

1. Подтверждение цены — по медиане группы: «медиана витрины ≥ need×0,65»; headroom <1,15 → тест, <1,0 → не брать. Затронет ~45 «оплатить» и все наборы.
2. Слить 20 дублирующих кластеров и разрулить конфликты решений до оплаты (838/839 vs 1365, 383 vs 619 и т.д.).
3. Исправить кол-во_план у тестов (25) и подписать каждый вариант закупки составом — чем именно набирается сумма.
4. Расшифровать 0,336296 по тарифам WB и перепроверить need на 5 реальных строках выплат; скорректировать все need (минимум — налог).
5. FESTIVE и комплекты с headroom <1,3 — в волну 2 (к свадебному сезону); доля комплектов в «оплатить» с 65 % снизить до ~40 %.
