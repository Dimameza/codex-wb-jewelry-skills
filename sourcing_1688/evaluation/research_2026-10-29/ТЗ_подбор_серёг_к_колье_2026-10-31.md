# ТЗ: подбор серёг к колье для наборов «колье + серьги»

Версия 1, 31.10.2026. Заменяет подбор от 28–31.10 (`pairs.py`, `rematch_2026-10-31.json`). Он не годится: пары собирались по общему сходству фото, и правила ниже не проверялись.

## 1. Цель

Для каждого колье из закупки найти серьги, с которыми колье выглядит как один комплект. Покупатель должен видеть, что вещи сделаны в паре, а не просто обе «золотые».

Результат — список пар. У каждой пары есть:
- признаки обоих предметов;
- проверка по каждому правилу;
- оценка глазами;
- решение: «комплект», «нет пары» или «спорно, на ревью».

## 2. Термины

| Термин | Значение |
|---|---|
| Колье | Позиция сегмента «колье», «чокер», «подвеска», «бусы» или колье из сегментов набора |
| Серьги | Позиция сегмента «серьги» из наших файлов заказа |
| Родные серьги | Серьги той же модели у того же продавца 1688: вариант в той же карточке («耳环», «耳钉», «耳饰») или комплект в одном варианте («项链+耳饰», «套装») |
| Главный элемент | Самая заметная часть изделия: кулон, центральный мотив, форма звеньев или форма самой серьги |
| Вставка | Камень, кристалл, страз, жемчуг, эмаль, смола, бусина |
| Масштаб | Изящный, средний, крупный или массивный (statement) |
| Семейство формы | Округлое или угловатое (см. п. 5.4) |
| Общий признак | Признак, который одинаков у колье и серёг: мотив, вставка, фактура или форма главного элемента. Металл и общий стиль общим признаком не считаются |

## 3. Входные данные

1. `scored.json`: сегмент, вес из карточки 1688, ¥, решение по канону, стоп-факторы.
2. Три описания фото на позицию (`descr`: Claude, Codex, Kimi).
3. Карточка 1688 (`det.colors`): варианты, материал, «风格», «流行元素».
4. Фото: `логика_ROI_фото/NNNN_1.jpg`, все фото карточки.
5. Разметка металла (`metal.json`) и CLIP-эмбеддинги (`analogs_emb.npz`) — только для предварительного отбора, а не для решения.

## 4. Карточка признаков предмета

Для каждого колье и каждой пары серёг заполняется карточка признаков.

| Признак | Значения | Источник |
|---|---|---|
| Металл / цвет покрытия | золото, серебро, розовое золото, два цвета, без металла | описания (2 из 3), иначе CLIP; при споре — глазами |
| Тип вставки | нет, страз/кристалл, жемчуг, эмаль, смола/янтарь, цветной камень, бусины, перламутр | описания, глазами |
| Цвет вставки | белый/прозрачный, чёрный, красный/бордо, зелёный, синий, розовый, коричневый/янтарный, разноцветный | описания, глазами |
| Доля вставки | нет; акцент (одна вставка или мелкие); основа (вставки занимают бо́льшую часть) | глазами |
| Масштаб | изящный, средний, крупный, массивный | описания («мелкий», «тонкий», «изящный», «средний», «крупный», «statement») + вес (п. 5.3) |
| Форма главного элемента | круг, овал, капля, кольцо, квадрат, прямоугольник, ромб, треугольник, сердце, цветок, лист, звезда, бант, спираль, волна, мятая/органическая, линия/гладкий обруч | описания, глазами |
| Семейство формы | округлое / угловатое / смешанное | по форме (п. 5.4) |
| Фактура металла | гладкая/зеркальная, мятая/«жидкая», молотковая, рифлёная, ажурная, цепь | описания, глазами |
| Мотив | цветок, лист, сердце, бант, звезда, змея, монета, крест, геометрия, без мотива | описания, глазами |
| Родные серьги | да (вариант / комплект) / нет | варианты карточки 1688 |

Если два описания из трёх расходятся по металлу, вставке или масштабу, признак определяют глазами. Позицию не пропускают.

## 5. Обязательные правила

Пара проходит, только если выполнены **все** правила 5.1–5.6.

### 5.1 Сначала родные серьги
1. Если у колье есть родные серьги, набор собирается только из них, а подбор не делается.
2. Если колье уже продаётся комплектом с серьгами (один вариант «колье + серьги» или «набор N предметов»), подбор не нужен, и позиция исключается из списка.
3. Если серьги видны только на фото, а отдельного варианта нет, это уточняют у продавца. До ответа подбор делается по общим правилам.

### 5.2 Металл одинаковый
1. Цвет металла у колье и серёг совпадает: золото к золоту, серебро к серебру.
2. Колье из двух цветов металла сочетается с серьгами из двух цветов или с серьгами основного цвета колье. Основной цвет — тот, которого больше на фото.
3. Розовое золото сочетается только с розовым золотом.

### 5.3 Масштаб совпадает
1. Масштабы колье и серёг различаются не больше чем на одну ступень: изящный ↔ средний, средний ↔ крупный, крупный ↔ массивный.
2. **К изящному колье — только изящные серьги**: гвоздики, маленькие кольца, короткие подвески. Крупные и массивные серьги к изящному колье не подходят.
3. К массивному колье не подходят мелкие гвоздики.
4. Начальные пороги по весу. После первых 30 пар их сверяют с оценкой глазами.

| Масштаб | Колье, г | Серьги (пара), г |
|---|---|---|
| Изящный | ≤ 15 | ≤ 8 |
| Средний | 16–40 | 9–20 |
| Крупный | 41–80 | 21–35 |
| Массивный | > 80 | > 35 |

Если вес из описаний и вес по порогам дают разный масштаб, решает оценка глазами.

### 5.4 Семейство формы одинаковое
1. Округлое семейство: круг, овал, капля, кольцо, сердце, волна, спираль, мятая/органическая форма, гладкий обруч.
2. Угловатое семейство: квадрат, прямоугольник, ромб, треугольник, геометрия с острыми углами.
3. **Квадратные и прямоугольные серьги не подходят к колье с круглым, овальным или каплевидным кулоном, к цепи с круглыми звеньями и к гладкому округлому обручу.** Обратное правило тоже действует: к угловатому кулону нельзя подбирать круглые серьги.
4. Цветок, лист, звезда и бант сочетаются только с тем же мотивом (п. 5.6).

### 5.5 Вставка совпадает
1. **Если в колье есть вставка, в серьгах есть вставка того же типа и того же цвета**: жемчуг к жемчугу, красный камень к красному камню, прозрачные стразы к прозрачным стразам.
2. Если вставка — основа колье (жемчужное колье, стразовое колье), то в серьгах вставка тоже основа или заметный акцент.
3. Если в колье вставок нет (гладкий или мятый металл), в серьгах нет крупных вставок. Мелкий страз-акцент допустим, только если он есть на кулоне колье.
4. Оттенок может различаться в пределах цветовой группы из п. 4. Например, белый и молочный жемчуг совместимы, а белый и золотистый (шампань) — уже спорно.

### 5.6 Есть хотя бы один общий признак
Кроме металла, у пары должен быть **хотя бы один общий признак**:
- тот же мотив (цветок — цветок, сердце — сердце);
- та же вставка (п. 5.5);
- та же фактура (мятая — мятая, молотковая — молотковая);
- та же форма главного элемента (капля — капля, кольцо — кольцо).

Только металл и общий стиль («оба скульптурные») — недостаточно, такая пара не проходит.

### 5.7 Ограничения по составу
1. Серьги со стоп-фактором (копия бренда и т. п.) не используются.
2. Одна модель серёг входит не больше чем в 3 набора. Иначе на витрине будет много одинаковых комплектов.
3. Серьги и колье должны быть доступны у продавца: в карточке 1688 есть вариант нужного цвета.

## 6. Процесс подбора

| Шаг | Действие | Выход |
|---|---|---|
| 1 | Проверить варианты карточки 1688 у каждого колье (п. 5.1). Разделить колье на «родные серьги», «уже комплект» и «нужен подбор» | список с типом |
| 2 | Заполнить карточку признаков (п. 4) для всех колье и всех серёг | таблица признаков |
| 3 | Для колье из группы «нужен подбор» отобрать серьги, которые проходят правила 5.2–5.5 и 5.7 по таблице признаков | кандидаты по правилам |
| 4 | Ранжировать кандидатов: сначала по числу общих признаков (п. 5.6), затем по сходству фото CLIP. Оставить до 8 на колье | лист кандидатов |
| 5 | Собрать листы: колье и рядом 8 кандидатов с номерами и признаками | `pair_sheets/*.jpg` |
| 6 | Два проверяющих независимо отмечают для каждого кандидата пункты чек-листа (п. 7) | две таблицы ответов |
| 7 | Свести ответы. Пара проходит, если оба проверяющих ответили «да» по всем пунктам. Расхождения разбирает третий проверяющий | итоговые пары |
| 8 | Собрать лист итоговых пар (колье + серьги рядом, крупно) и проверить весь лист ещё раз | лист приёмки |
| 9 | Посчитать экономику набора по канону: ¥ колье + ¥ серёг, упаковка 20 ₽, рынок комплектов WB без ценового фильтра, правило подтверждения и запас ≥ 1,0 | `final_sets_canon.json` |

Если для колье нет ни одной пары, решение — «нет пары». Ослаблять правила ради пары нельзя.

## 7. Чек-лист проверки глазами

По каждой паре проверяющий отвечает «да» или «нет»:

1. Металл одного цвета?
2. Масштаб близкий? Нет ли крупных серёг к изящному колье или мелких гвоздиков к массивному?
3. Семейство формы одно? Нет ли квадратных серёг к круглому или овальному кулону?
4. Если в колье есть вставка, есть ли в серьгах вставка того же типа и цвета?
5. Есть ли хотя бы один общий признак, кроме металла? Какой именно — записать.
6. Похоже ли это на комплект одной коллекции, если положить предметы рядом?

Пара проходит только при шести ответах «да». В поле «общий признак» записывается конкретный признак, например «мятый металл» или «красный камень в круглой оправе».

## 9. Результат и формат

1. `наборы_серьги/pairs_v2.json`: по каждому колье — тип (родные / уже комплект / подбор), признаки колье, выбранные серьги и их признаки, ответы двух проверяющих, общий признак, решение.
2. `наборы_серьги/pair_sheets/`: листы кандидатов и лист приёмки итоговых пар.
3. Пересчёт экономики (`sets_canon.py`) и плана (`consensus_canon.py`), обновление вкладки «Наборы» в HTML-отчёте. В таблице есть колонка «Общий признак».
4. Короткий отчёт: сколько колье с родными серьгами, сколько комплектов подобрано, для скольких нет пары, сколько наборов идут в план.

## 10. Приёмка

1. Каждая пара из плана выполняет все правила 5.1–5.7. Это видно в `pairs_v2.json`.
2. У каждой пары записан конкретный общий признак.
3. Лист приёмки просмотрен целиком, явных несочетаний нет.
4. Ни одно колье с родными серьгами или из группы «уже комплект» не получило подобранные серьги.
5. Ни одна модель серёг не стоит больше чем в 3 наборах.
6. Файлы заказов не изменены.

## 11. Контроль русского языка

Требования к тексту отчёта, подписей и комментариев к парам:
1. Без причастных и деепричастных оборотов. Причастие с зависимыми словами заменять придаточным с «который» или отдельным предложением. Деепричастие заменять глаголом или предлогом: «включая» → «в том числе», «учитывая» → «с учётом».
2. Термины — по разделу 2: «родные серьги», «общий признак», «семейство формы», «масштаб».
3. Перед сдачей — поиск по окончаниям причастий (-ущ-, -ющ-, -ащ-, -ящ-, -вш-) и деепричастий (-я, -в, -вши) и правка найденного.
